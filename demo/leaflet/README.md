# Ask Mavis leaflet

Double-sided A5 leaflet for libraries, GP surgeries, chemists, lunch clubs, U3A, WI and community centres.

- `ask-mavis-leaflet-A5-print.pdf`: print-ready, A5 (148 x 210 mm) with 3 mm bleed on every edge (page 154 x 216 mm), text kept 8 mm inside the trim. Two pages: front and back. Send this to a printer and ask for "A5, double-sided, with 3 mm bleed".
- `ask-mavis-leaflet-front.png` / `-back.png`: previews.
- `leaflet-source.html`: the source, to change the wording.
- Editable Canva version (A4, made by Canva's AI): https://canva.link/mhdszcdclhhjnhi

Before printing, fill in:
1. A photo in the dashed box (your nan, or a stock photo).
2. The website address, and a QR code pointing to it.
3. Only say "Search for Ask Mavis in the Play Store" once the app is actually live there.
