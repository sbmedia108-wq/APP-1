# Site Queue marketing pack (v2)

Marketing for Site Queue (sitequeue.uk), the all-in-one construction site app launching in 2027. Prepared by SB Media.

- **Playbook** (strategy, who to email, email templates, plan, budget): shared doc "Site Queue Marketing Playbook".
- **Founder pitch deck** (17 slides): "Site Queue Go-to-Market Pitch", exports to PowerPoint or PDF.

| Path | What it is |
| --- | --- |
| `site-queue-proposal.pdf` | Client proposal: recommendation, approach, what's included, timeline, working together, launch budget, sign-off |
| `site-queue-client-questionnaire.pdf` | 20 questions for the founder, with space to answer |
| `sb-media-evening-plan.pdf` | Internal: SB Media's evening work plan (about 8 hours a week) |
| `video/site-queue-1x1.mp4`, `video/site-queue-16x9.mp4` | 59-second animated product video with British voiceover and original music, square and widescreen |
| `video/site-queue-music.mp3`, `video/voiceover-script.md` | Music track on its own, and the voiceover script |
| `website/site-queue-demo-form-guide.pdf` | 2-page guide for Luke: how the demo form looks, what it asks, what happens after, go-live checklist |
| `site-queue-launch-action-plan.pdf` | 10-page client action plan: every step to launch with owner, due date and tick box |
| `site-queue-outreach-targets.xlsx` | 112 target organisations in 10 segments, roles, pitch angle, wave and status tracker |
| `graphics/linkedin-banner.png`, `og-image.png`, `email-header.png` | LinkedIn cover, website share image, email header |
| `graphics/post-01…12-*.png` | 12 social posts (1080 × 1080) covering every feature, the founding-site offer and advertisers |
| `graphics/one-pager-a4.pdf` | A4 sales sheet (contact email still to add) |
| `graphics/pullup-banner-preview.png` | Event banner layout; rebuild in vector for print |
| `graphics/phone-*.png` | Transparent phone screens (home, logistics, inductions, map, drawings, alert, feed, advert) |
| `graphics/preview-all.png` | Every graphic on one sheet |
| `brand/brand-basics.pdf` | Colours, type and rules |
| `brand/screens/dashboard-*.png` | Real screenshots of the demo web dashboard |
| `source/` | HTML/Playwright source for every graphic: `node graphics2.js` and `node assets2.js` re-render them |

Brand: charcoal `#1F1F1F`, hi-vis lime `#80D83B`, site green `#2E5A14`, concrete `#ECEDE8`, ballast `#7D827C`. Type: Barlow Condensed (headlines) and Barlow (body).

Phone screens are designed from the demo's data. Replace them with real mobile app screenshots when available.
Agency credit: "Design by SB Media" appears on print pieces and the brand sheet only, not on public social posts or ads.
