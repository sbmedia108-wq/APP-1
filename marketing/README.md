# Site Queue marketing pack

Marketing assets for Site Queue (sitequeue.uk), a UK construction site coordination app launching in 2027.
The full playbook (findings, fixes, positioning, who to email, email templates, channels, step-by-step plan,
budget, questions for the founder) is in the shared doc "Site Queue Marketing Playbook".

| Path | What it is |
| --- | --- |
| `site-queue-outreach-targets.xlsx` | 112 target organisations in 10 segments, with roles to contact, pitch angle, priority, wave and a status tracker. Verify each company before contacting. |
| `graphics/linkedin-banner.png` | LinkedIn cover, 1584 × 396 |
| `graphics/og-image.png` | Website share image, 1200 × 630 |
| `graphics/email-header.png` | Email / newsletter header, 1200 × 400 |
| `graphics/post-1…6-*.png` | Six 1080 × 1080 social posts (teaser, forklift queue, inductions, programme, founding sites, advertisers) |
| `graphics/one-pager-a4.pdf` | A4 sales sheet (contact email still to confirm) |
| `graphics/pullup-banner-preview.png` | Pull-up banner layout; rebuild in vector for print |
| `graphics/preview-all.png` | All graphics on one sheet |
| `brand/sq-logo.png`, `brand/icon-512.png`, `brand/site_queue_splash.png` | Current logo files from the live site (raster only; a vector logo is still needed) |
| `brand/screens/dashboard-*.png` | Eight clean screenshots of the demo web dashboard (2880 × 1800) |

Brand colours: charcoal `#1F1F1F`, lime green `#80D83B`, dark green `#427F1E`. Font used in graphics: Inter.
