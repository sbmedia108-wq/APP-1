# LinkedIn company page: setup pack

Everything you need to set up the Site Queue company page in about 30 minutes. You create it from your own LinkedIn profile (go to **For Business**, then **Create a Company Page**, then **Company**), then add Luke as a super admin.

## Page details (copy and paste)

| Field | What to put |
| --- | --- |
| Name | Site Queue |
| LinkedIn public URL | linkedin.com/company/sitequeue (or `sitequeueuk` if taken) |
| Website | https://sitequeue.uk |
| Industry | Software Development |
| Company size | 2–10 employees |
| Company type | Privately held |
| Location | [Luke's town], United Kingdom |
| Logo | `brand/icon-512.png` |
| Cover image | `graphics/linkedin-banner.png` |
| Custom button | **Visit website**, linking to https://sitequeue.uk/book-a-demo/ |

**Tagline** (120 characters max):

> Run the whole site from one app. Logistics, inductions, programme, drawings and safety for UK construction sites.

**About** (overview):

> Site Queue is one app for everything that happens on a UK construction site.
>
> It was built by a contractor who'd spent years waiting for the forklift, chasing the main contractor and working from out-of-date drawings, so he built the fix himself.
>
> One app, every role on site:
> • Forklift and delivery queue, with live wait times
> • Digital inductions with CSCS cards, pass marks and signatures
> • Master programme and plot-by-plot tracking
> • Current drawings, RAMS, permits and certificates
> • First-aid alerts and hazard reporting, pinned on a live site map
> • A site feed instead of six WhatsApp groups
> • A web dashboard for the office
>
> The app is free for trades on site. Main contractors and subcontractors pay per site.
>
> Launching in 2027. Early access is open now, with an early-bird rate for sites that sign up before launch: sitequeue.uk

## After it's created

1. **Admin tools → Manage admins:** add Luke as **Super admin**. He needs to be connected to you on LinkedIn first.
2. Invite your own connections to follow the page. LinkedIn gives free monthly invites, so use them all.
3. Ask Luke to add Site Queue as his current job ("Founder, Site Queue") so the page shows on his profile.
4. Add the LinkedIn Insight Tag to the website (**Analytics → Insight Tag**) and pass it to Luke for the site.
